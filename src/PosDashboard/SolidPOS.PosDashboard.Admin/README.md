# SolidPOS PosDashboard Admin

React/Vite admin foundation for SolidPOS.

## Commands

```bash
npm install
npm run build
npm run self-test
```

## Environment

```text
VITE_POSSERVER_BASE_URL=https://full-metal-cash-production.up.railway.app
```

## Scope

- Login against `/api/v1/auth/login`.
- Admin shell layout.
- Initial operational overview.
- Health/readiness and sync status client.
- Tailwind foundation.
