# SolidPOS PILOT-01 Operator Brief

## What this pilot setup validates

This phase validates the environment before real controlled sales. It does not add new POS features and does not replace business training.

## Operator rules

- Do not use demo tenant/users.
- Use only the production pilot tenant.
- Use only the active store selected for the pilot.
- Record every issue in the daily pilot log.
- Do not continue if a GO/NO-GO checklist returns NO-GO.
- Do not paste passwords, database URLs, JWT keys, or provision keys into chat or Git.

## First controlled operation after PILOT-01

The next phase is PILOT-02, where real POS transactions are validated. PILOT-01 only confirms the environment is ready.
