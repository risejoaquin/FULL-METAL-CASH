# GA-03 — Daily Support Operating Checklist

- health/live = alive; health/ready and database = ready.
- review API failed-request and p95 latency signals.
- review retry_pending, retry age, stale processing, conflicts and new dead-letters.
- verify retained historical dead-letter remains documented and non-executable.
- review failed payments last 24 hours.
- review open cash shifts and cash differences.
- review inventory/reconciliation risk.
- review audit evidence freshness.
- assign owner, severity and next action to every breached threshold.
- review release/update incidents and rollback readiness.
- preserve evidence without secrets.
