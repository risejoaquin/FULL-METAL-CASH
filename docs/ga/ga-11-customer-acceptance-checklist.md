# GA-11 — Customer Acceptance Checklist

## Customer acceptance

- [ ] Customer list endpoint validated.
- [ ] Customer-facing receipt flow remains available through prior receipt validation evidence.
- [ ] Returns/refunds expectations are documented.
- [ ] Support route for incidents is documented.
- [ ] Known capacity condition is disclosed: Concurrency 3+ can produce 400 upstream error on current Railway/upstream path.
- [ ] General Availability public launch remains not activated.

## Evidence

The validator records customer API status, customer counts, completed sale counts, active digital receipt count when present, blockers and conditions.
