# LGA-02 Real Sales Cycle Record

LGA-02 requires real sales and payments after the LGA-01 baseline. The validator compares completed sales and payments in the last 24 hours against baseline values and minimum new activity.

Default baseline: 3 completed sales and 3 payments. Default minimum new cycle: 3 completed sales and 3 payments.


## Stability loop

This record is part of the LGA-02 stability loop. It confirms that real sales, completed sales, and payments increase after the LGA-01 baseline without increasing the accepted sync conflict or dead letter baselines.
