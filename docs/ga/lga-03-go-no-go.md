# LGA-03 Go/No-Go

## GO para continuar burn-in

- Checkpoint sin blockers.
- Public GA not activated.
- Limited GA estable.

## GO para LGA-04

- Multi-day burn-in finalizado.
- Días requeridos cubiertos con manifests sin blockers.
- sync conflicts y dead letter no incrementan.
- negative stock se mantiene en zero.
- open shifts se mantienen cerrados.
- Public GA not activated.

## NO-GO

- Aumento de sync conflicts.
- Aumento de dead letter.
- negative stock mayor a zero.
- open shifts huérfanos.
- Public GA activado accidentalmente.
- Ventas, pagos o recibos por debajo del mínimo de burn-in.
