# EXP-08 — Incident Evidence Template

Required fields:

- incident id
- tenant id
- base url
- store id
- terminal id
- user/session context if applicable
- started at
- detected by
- severity
- symptoms
- logs
- manifest
- sql evidence
- endpoint evidence
- screenshots when applicable
- containment decision
- rollback decision
- escalation owner
- next action

Do not include passwords, tokens, DATABASE_URL, or secret material in evidence.
