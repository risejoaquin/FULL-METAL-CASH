# EXP-05 Daily Dashboard Checklist

## Daily review

Ejecutar diariamente durante expansión limitada.

## Health

- Validar health/live.
- Validar health/ready.
- Validar database ready.
- Validar required tables present.

## Sync

- Revisar processed sync.
- Revisar retry_pending.
- Revisar dead_letter.
- Revisar pending conflicts.
- Revisar resolved conflicts.

## Cash

- Revisar open cash shifts.
- Revisar cash shift differences.
- Revisar expected cash vs counted cash.

## Inventory

- Revisar negative inventory.
- Revisar low stock si la métrica existe.
- Abrir reconciliation si negative inventory sigue vivo.

## Audit

- Revisar audit events recientes.
- Confirmar que ventas, terminales, tiendas y recibos tienen evidencia.

## Output diario

- dashboard timestamp.
- owner.
- blocker / condition / GO.
- action tomada.
- evidence adjunta.
