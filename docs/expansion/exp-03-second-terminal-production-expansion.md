# EXP-03 Second Terminal Production Expansion

## Objective

Validate a second terminal in production under GO LIMITED EXPANSION.

## Required evidence

- second terminal enrollment.
- terminal register.
- sync bootstrap.
- independent cash shift.
- controlled sale.
- terminal-filtered sales read model.
- digital receipt.
- audit trail.
- SQL cross-check.
- rollback path.
- GO/NO-GO.

## Decision

EXP-03 is GO only when the second terminal operates without breaking the first terminal or store operations.
