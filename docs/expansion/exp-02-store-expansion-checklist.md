# EXP-02 Store Expansion Checklist

Pre-expansion: confirm production readiness, catalog, inventory, users/roles, rollback owner, GO_LIMITED_EXPANSION.

Store setup: validate store, store code, catalog assignment, inventory baseline, cash drawer policy and dashboard by store.

Evidence: health/readiness, SQL cross-check, audit event, GO/NO-GO approval.

Rollback: use store rollback runbook when any blocker appears.
