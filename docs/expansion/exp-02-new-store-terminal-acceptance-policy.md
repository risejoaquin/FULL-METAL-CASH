# EXP-02 New Store / New Terminal Acceptance Policy

Acceptance for new store: tenant isolation, store isolation, catalog, inventory, cash drawer policy, reporting and audit trail.

Acceptance for new terminal: terminal enrollment, bootstrap sync, login/session, cash shift independent, sales by terminal, dashboard monitoring, rollback path.

Limited expansion: one new store or one new terminal at a time. Requires pilot evidence, criteria and GO/NO-GO.
