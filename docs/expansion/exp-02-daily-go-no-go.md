# EXP-02 Daily GO/NO-GO Matrix

GO: health alive, readiness ready, database ready, admin login, protected metrics, pending conflicts 0, failed payments last 24 hours 0, audit endpoint works.

Conditional GO: retry_pending monitored, dead_letter triaged, negative inventory tracked.

NO-GO: readiness failure, database unavailable, pending conflicts, failed payments, no rollback owner, missing evidence.

Approval required daily.


## Monitoring / Monitoreo

Daily approval requires operational monitoring evidence for health/readiness, protected metrics, sync status, dead-letter queue, pending conflicts, failed payments, negative inventory, audit events, and rollback owner confirmation.
