# EXP-08 — Support Bitacora

Each support log entry must include:

- bitacora id
- support log timestamp
- incident id when applicable
- operator
- decision
- evidence collected
- condition observed
- next action
- owner
- status

Example statuses:

- observed
- triaged
- escalated
- contained
- resolved
- closed

The bitacora is not a replacement for audit events. It is an operational support log.
