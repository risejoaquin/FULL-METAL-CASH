# BETA-10 Closure Metrics

Required metrics:
- beta summary
- customer count
- store count
- terminal count
- sales count
- payment count
- support incidents
- SLA performance
- sync reliability
- release readiness
- known conditions
- blockers
- final decision
- next roadmap

Support incidents are audit-classified support/incident actions because the current schema has no dedicated support-ticket table. Operational support conditions are reported separately.
