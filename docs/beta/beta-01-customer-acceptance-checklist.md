# BETA-01 Customer Acceptance Checklist

## Onboarding acceptance
- [ ] Beta customer profile identified and active in tenant scope.
- [ ] Store and terminal assignment validated.
- [ ] Admin can authenticate and access intended administrative resources.
- [ ] Catalog baseline is visible/usable; SQL cross-check confirms source-of-truth records.
- [ ] Price list and current MXN product pricing are valid.
- [ ] Controlled update channel is available.
- [ ] Support path and severity model are understood.
- [ ] Audit evidence is available.
- [ ] Known non-blocking conditions are recorded.

## Sign-off placeholders
- Operator sign-off: `PENDING`
- Customer/admin sign-off: `PENDING`
- Production validation: `PENDING USER VALIDATION`

BETA-01 does not claim customer acceptance until the production validation script passes and the operational sign-off is completed.
