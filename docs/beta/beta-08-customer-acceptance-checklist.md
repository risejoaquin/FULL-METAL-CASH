# BETA-08 Customer Acceptance Checklist

- sales acceptance — completed/returned sale and approved payment evidence
- cash acceptance — closed shift evidence and no unreconciled 24h cash difference
- receipts acceptance — active digital receipt evidence
- returns/refunds acceptance — completed return and approved refund evidence
- catalog/pricing acceptance — active product and persisted price evidence
- user/admin acceptance — active users, RBAC assignment and store access evidence
- offline acceptance — processed schema 4 sync, zero pending conflict, zero legacy schema event
- support acceptance — audit evidence and BETA-07 monitoring prerequisite
- release/update acceptance — active non-mandatory beta Velopack release with signature and rollback version

All items must be PASS before GO BETA-09.
